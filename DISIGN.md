  问卷系统 · 完整方案

  一、整体架构（一句话）

  浏览器（Vue 界面，5174）↔ Flask 后端（5000）↔ SQLite（一个 .db 文件）。

  二、数据模型（6 张表）

  1. users（用户）

  ┌───────────────┬──────┬────────────────────────┐
  │     字段      │ 类型 │          说明          │
  ├───────────────┼──────┼────────────────────────┤
  │ id            │ 整数 │ 主键自增               │
  ├───────────────┼──────┼────────────────────────┤
  │ username      │ 文本 │ 唯一，不能重名         │
  ├───────────────┼──────┼────────────────────────┤
  │ password_hash │ 文本 │ 哈希密码，不存明文     │
  ├───────────────┼──────┼────────────────────────┤
  │ token         │ 文本 │ 登录后生成的随机 token │
  ├───────────────┼──────┼────────────────────────┤
  │ avatar        │ 文本 │ 头像，默认值           │
  ├───────────────┼──────┼────────────────────────┤
  │ email / phone │ 文本 │ 占位，先空着           │
  ├───────────────┼──────┼────────────────────────┤
  │ created_at    │ 时间 │ 注册时间               │
  └───────────────┴──────┴────────────────────────┘

  2. questionnaires（问卷）

  ┌─────────────────────────┬──────┬────────────────────────────────────┐
  │          字段           │ 类型 │                说明                │
  ├─────────────────────────┼──────┼────────────────────────────────────┤
  │ id                      │ 整数 │ 主键                               │
  ├─────────────────────────┼──────┼────────────────────────────────────┤
  │ user_id                 │ 整数 │ 作者（外键）                       │
  ├─────────────────────────┼──────┼────────────────────────────────────┤
  │ type                    │ 文本 │ test / relay / exam                │
  ├─────────────────────────┼──────┼────────────────────────────────────┤
  │ title                   │ 文本 │ 问卷名                             │
  ├─────────────────────────┼──────┼────────────────────────────────────┤
  │ status                  │ 文本 │ draft（草稿）/ published（已发布） │
  ├─────────────────────────┼──────┼────────────────────────────────────┤
  │ created_at / updated_at │ 时间 │                                    │
  └─────────────────────────┴──────┴────────────────────────────────────┘

  3. questions（题目）

  ┌──────────────────┬──────┬───────────────────────────────┐
  │       字段       │ 类型 │             说明              │
  ├──────────────────┼──────┼───────────────────────────────┤
  │ id               │ 整数 │ 主键                          │
  ├──────────────────┼──────┼───────────────────────────────┤
  │ questionnaire_id │ 整数 │ 属于哪个问卷                  │
  ├──────────────────┼──────┼───────────────────────────────┤
  │ type             │ 文本 │ single（单选）/ scale（量表） │
  ├──────────────────┼──────┼───────────────────────────────┤
  │ title            │ 文本 │ 题干                          │
  ├──────────────────┼──────┼───────────────────────────────┤
  │ order            │ 整数 │ 排序                          │
  └──────────────────┴──────┴───────────────────────────────┘

  4. options（选项） —— 单选和量表共用这一张表

  ┌─────────────┬──────┬────────────────┐
  │    字段     │ 类型 │      说明      │
  ├─────────────┼──────┼────────────────┤
  │ id          │ 整数 │ 主键           │
  ├─────────────┼──────┼────────────────┤
  │ question_id │ 整数 │ 属于哪道题     │
  ├─────────────┼──────┼────────────────┤
  │ text        │ 文本 │ 选项文字       │
  ├─────────────┼──────┼────────────────┤
  │ score       │ 整数 │ 这个选项的分值 │
  ├─────────────┼──────┼────────────────┤
  │ order       │ 整数 │ 排序           │
  └─────────────┴──────┴────────────────┘

  ▎ 量表题就是"自动生成 5 个选项、分值 1~5"的特殊情况，不单独建表。这样单选/量表一套逻辑通吃。

  5. result_cards（结果卡片）

  ┌───────────────────────┬──────┬──────────────┐
  │         字段          │ 类型 │     说明     │
  ├───────────────────────┼──────┼──────────────┤
  │ id                    │ 整数 │ 主键         │
  ├───────────────────────┼──────┼──────────────┤
  │ questionnaire_id      │ 整数 │ 属于哪个问卷 │
  ├───────────────────────┼──────┼──────────────┤

  ├───────────────────────┼──────┼──────────────┤

  ├───────────────────────┼──────┼──────────────┤
  │ order                 │ 整数 │ 排序         │
  └───────────────────────┴──────┴──────────────┘

  6. user_actions（我的行为） —— 收藏/喜爱/使用/浏览共用一张表

  ┌──────────────────┬──────┬────────────────────────────────┐
  │       字段       │ 类型 │              说明              │
  ├──────────────────┼──────┼────────────────────────────────┤
  │ id               │ 整数 │ 主键                           │
  ├──────────────────┼──────┼────────────────────────────────┤
  │ user_id          │ 整数 │ 谁                             │
  ├──────────────────┼──────┼────────────────────────────────┤

  ├──────────────────┼──────┼────────────────────────────────┤

  ├──────────────────┼──────┼────────────────────────────────┤
  │ created_at       │ 时间 │                                │
  └──────────────────┴──────┴────────────────────────────────┘

  四、前端结构

  页面 + 路由

  ┌─────────────┬─────────────────────────────┬────────────────┐
  │    路由     │            页面             │   是否要登录   │
  ├─────────────┼─────────────────────────────┼────────────────┤
  │ /login      │ 登录/注册页                 │ 否（首个页面） │
  ├─────────────┼─────────────────────────────┼────────────────┤
  │ /           │ 首页（公开问卷广场）        │ 是             │
  ├─────────────┼─────────────────────────────┼────────────────┤
  │ /create     │ 新建（新建按钮 + 我创建的） │ 是             │
  ├─────────────┼─────────────────────────────┼────────────────┤
  │ /my         │ 我的（五类 + 用户信息）     │ 是             │
  ├─────────────┼─────────────────────────────┼────────────────┤
  │ /editor/:id │ 问卷编辑器                  │ 是             │
  ├─────────────┼─────────────────────────────┼────────────────┤
  │ /q/:id      │ 填写页                      │ 否（免登录）   │
  ├─────────────┼─────────────────────────────┼────────────────┤
  │ 结果页      │ 填完显示分数+文案           │ 否             │
  └─────────────┴─────────────────────────────┴────────────────┘

  组件：题目编辑器、选项编辑器、结果卡片编辑器、问卷卡片等。

  状态：token 存 localStorage，用户信息登录后拉取缓存；暂不用 Pinia。

  五、核心逻辑

  计分：每题选中的选项取其 score，全部累加 = 总分。

  结果匹配：遍历 result_cards，找到 min_score ≤ 总分 ≤ max_score
  的那张，返回文案；若分数没落进任何区间，返回一个兜底文案。

  分享：发布后生成链接 http://localhost:5174/q/{id}，任何人打开就能填（走免登录接口）。

  接龙/考试：只在"选类型"时可选，点了提示"开发中"，不建表、不做逻辑。
